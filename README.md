# SICK Website v4

Production-oriented visual prototype for SICK Streetwear.

## Improvements in v4
- Uses clean transparent SICK wordmark and CK monogram assets; no CSS inversion/filter on logos.
- WebP is used for all photographic assets.
- Hero image is prioritized; below-fold images use lazy loading + async decoding.
- Product modal paths use WebP assets correctly.
- Readability increased for body, product, journal, footer and metadata text.
- Muted text contrast increased against the black background.
- Mobile product descriptions remain visible.
- Product index corrected to 01/04, 02/04, 03/04, 04/04.
- Functional demo cart drawer with quantities, remove controls and subtotal.
- Newsletter form has explicit invalid-email visual feedback.
- Loading background prevents empty white flashes while images load.
- Keyboard focus styles and aria labels improved.

## Run
Open `index.html` in a browser.

Checkout remains a front-end demo until connected to inventory, customer data and a payment provider.
